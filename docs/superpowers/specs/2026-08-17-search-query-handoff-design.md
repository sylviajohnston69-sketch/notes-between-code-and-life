# 搜索参数衔接修复设计

## 目标

让首页侧栏以 `GET /search/?q=关键词` 提交后，搜索页保留该关键词，并在搜索索引加载完成后立即显示匹配结果。

## 方案

新增一个只负责从 URL 查询字符串读取 `q` 并写入搜索输入框的小型纯函数。搜索页改为由 Astro 打包客户端脚本，在读取索引前调用该函数；现有索引加载结束时的 `search()` 调用保持不变，因此预填关键词会自动参与第一次搜索。

不修改表单、页面布局、搜索匹配规则、博客名称、仓库名称、Vercel 项目或生产网址。

## 错误与边界

- URL 中没有 `q` 时保持输入框原值，不引入错误。
- 空的 `q` 继续走现有“输入关键词开始搜索”状态。
- 百分号编码和中文由标准 `URLSearchParams` 解码。

## 验证

- 先添加失败单元测试，证明中文编码的 `?q=` 目前无法填充输入框。
- 实现最小辅助函数并让聚焦测试转绿。
- 运行完整测试与生产构建。
- 在部署后通过真实搜索 URL 验证输入框保留关键词并显示结果。
