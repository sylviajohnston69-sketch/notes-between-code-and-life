# 博客展示名称调整设计

## 目标

把博客对外显示名称从“在代码与生活之间”调整为“在思考与生活之间”，同时保持现有 GitHub 仓库名、Vercel 项目名和公开网址不变。

## 改动范围

- 更新 `src/config/site.ts` 中的站点标题。页头、浏览器标题和页面元信息继续从这一处读取。
- 更新 `README.md` 的一级标题，使项目说明与线上名称一致。
- 保留历史设计文档和实施计划中的旧名称，因为其中已明确说明旧名称只是搭建阶段示例。
- 不修改仓库 `notes-between-code-and-life`、Vercel 项目或 `https://notes-between-code-and-life.vercel.app`。

## 验证

- 先增加一个针对站点标题配置的失败测试，再修改标题使其通过。
- 运行完整测试、隐私检查和生产构建。
- 检查生成页面包含新名称，且公开页面不再显示旧名称。
- 重新部署到现有 Vercel 项目，验证正式域名仍可访问，首页和文章页显示新名称。

## 风险与处理

唯一风险是只修改某个页面而造成名称不一致。继续使用 `src/config/site.ts` 作为唯一运行时配置源，并通过测试与构建产物检查避免遗漏。公开链接保持不变，因此不需要重定向或迁移。
